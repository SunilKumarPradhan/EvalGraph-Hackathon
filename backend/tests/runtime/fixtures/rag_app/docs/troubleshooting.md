# Troubleshooting

A red blinking ring light means the water tank is empty or not seated. Refill it and push it down until it clicks.

If coffee drips slowly, the grind is too fine or the machine needs descaling.

A loud pumping noise with no water flow means air in the system. Run one empty cycle with the steam wand open.

Error code E7 means the boiler overheated. Switch the machine off for 30 minutes before using it again.
